# Docs

One file per feature. Each file has two short sections:

- **Overview** — plain-language explanation of what the feature does and why, written for a
  non-technical reader or a new dev with zero context on this project.
- **Technical notes** — the actual implementation: files touched, key functions/logic, and any
  gotchas (e.g. selector fragility, API quirks) — written for a dev who needs to modify it later.

These are quick orientation docs, not exhaustive documentation. See `PLAN.md` at the repo root for
the overall build roadmap.
